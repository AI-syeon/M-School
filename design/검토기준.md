# 최초 기획안 검토 기준

이 파일은 실제 플레이 검증 결과가 아닌 문서 검토 기준이다.

| 사용자 요구 | 문서에서 확인할 증거 | 합격 기준 |
|---|---|---|
| 도트 픽셀 아트 마법학교 | 시점·캐릭터·공간·마법 피드백 지침 | 생활 동선과 상호작용을 읽을 수 있는 아트 규칙 |
| 학교에 다니는 감각 | 시간표, 수업, 친구, 공동공간, 행사 | 하루 안에서 배움→활용→인물 반응이 연결 |
| 스타듀밸리 유사 타깃 | 일상 선택, 성장, 관계, 부담 조절 | 복귀가 쉽고 영구적인 놓침을 최소화 |
| 많은 NPC 소통 | 인물별 욕구·생활·관계 사건·반응 | 호감도 숫자 외에 기억과 관계 변화 존재 |
| 마법으로 다양한 콘텐츠 | 마법별 생활·탐험·전투 쓰임 | 같은 마법이 최소 두 종류 이상의 행동을 확장 |
| 전투 | 조작, 적, 패배, 난이도, 보상 | 전투 자체의 재미와 생활 플레이어의 접근 경로 모두 설명 |
| 전체 스토리와 자유 순서 | 의존 관계, 사건 상태, 진실 전달, 결말 조건 | 고정 도입·결말 사이의 독립 사건 순서가 자유 |
| 약 40시간 | 콘텐츠별 수량×평균 시간, 중복 제거 | 강제 대기나 반복 채집으로 시간 채우지 않음 |
| 전체 플레이에 지장 없음 | 경제·시간·해금·필수품·NPC의 실패 복구 | 주요 진행을 영구 차단하는 의존성 없음 |
| Claude 사용 | 실제 대화와 수신한 제안, 반영 내역 | 모델 사용을 추정하거나 꾸미지 않음 |
| 인간이 이해하기 쉬움 | 요약, 표, 예시 하루, 사건 예시 | 핵심 루프와 다음 행동을 설명만 읽고 이해 가능 |

## 반드시 따로 계산할 것

1. 사건 속 전투를 별도 전투 시간으로 재집계하지 않는다.
2. 관계 사건 안의 대화는 일상 대화 시간에서 제외한다.
3. 학교 행사의 준비가 제작 프로젝트와 겹치면 한쪽에만 귀속한다.
4. 최단 메인 루트와 주요 콘텐츠 소진 루트를 구분한다. 40시간을 보장된 측정값으로 말하지 않는다.
5. 선택한 해결법 하나의 시간만 플레이 시간에 넣는다. 대체 경로는 제작량에만 반영한다.
6. 메뉴에서 멈춘 시간, 실제 활동 시간, 달력의 경과를 혼동하지 않는다.

## 진행 막힘 점검 시나리오

- 출석하지 않음 / 특정 NPC를 만나지 않음 / 선물을 주지 않음.
- 돈을 전부 쓰고 재료를 판매함 / 제작에 실패함 / 전투에서 연속 패배함.
- 탐험 사건을 역순으로 해결함 / 단서를 공식 의뢰 전에 획득함.
- 행사 날짜를 지나침 / 장기간 잠만 잠 / 학기 목표보다 먼저 진실을 발견함.
- 퀘스트 도중 저장·종료 / 인벤토리가 가득 참 / 동행 NPC가 일정에서 이탈함.
- 엔딩 직전에 남은 선택 사건을 보류함 / 엔딩 후 기존 장소를 다시 방문함.
