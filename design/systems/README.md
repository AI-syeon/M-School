# Magic Campus 시스템 기획서

2026-11-01 · 설계 제안 v1 · 구현 착수용 · 2026-11-02 작성 형식 개정(함수 호출 칸, 이벤트 = Row 하나)

**시각 자료 포함판:** [그림으로 읽는 시스템 기획서 HTML](시스템_기획서.html). 전체 구조·이벤트 단계·이동 경로·제어권·시간 정지·저장 복구를 그림과 설명으로 읽을 수 있다. 개발용 본문과 실제 JSON도 한 파일에 포함한다.

이 문서는 기존 콘텐츠를 실행하기 위한 공통 시스템의 책임과 계약을 정의한다. 콘텐츠 기획의 수량·서사·화면 시안을 대체하지 않는다. JSON으로 추가할 수 있는 것은 **등록된 함수(조건·효과·명령)를 호출 문자열로 조합한 콘텐츠**다. 새로운 전투 규칙이나 새 퍼즐 원리에는 시스템 코드와 새 계약이 필요하다.

**작성 형식 개정(2026-11-02):** 이벤트는 JSON Row 하나이고 한 행동은 한 칸의 함수 호출(`move npc.serin dest.snack / say npc.serin "…"`)이다. 문법과 결정은 [함수 문법](full-design/11-function-syntax.md), 파서는 `tools/parse-calls.cjs`. 실행·임대·저장·커밋 계약은 그대로다.

4. [콘텐츠 작성과 데이터 계약](04-data-authoring.md): 이벤트 Row, 호출 문법, 함수 사전, 시험 맵, 실행 예시, 진단.

## 조사 범위와 현재 기반

프로젝트와 상위 디렉터리에서 AGENTS.md가 발견되지 않았다. 프로젝트의 숨김 파일 포함 목록에 게임 프로젝트·패키지 설정·게임 런타임·저장소 메타데이터는 없었다. `design`의 최종 Markdown 17절, 일관성 규칙, 검토 기준·결과, Claude 작업 기록을 읽었다. 기존 CJS는 기획 HTML·화면 갤러리 생성/검사 도구이며 게임 코드가 아니다. HTML과 이미지 무결성은 기존 검사기로 확인했다. 기존 PNG 16개의 화면을 이번 작업에서 시각적으로 다시 검토하지 않았으며 시스템 요구의 근거로 삼지 않았다. 과거 Claude 대화 링크는 작업 기록의 이력이며 이번 작업에서 원문 대화를 열었다고 주장하지 않는다.

Node.js v24.22.1을 실행 확인했다. dotnet 실행 파일은 검색되지만 기존 게임 코드는 없다. Python 명령은 Windows 앱 별칭의 실행 오류가 있어 사용하지 않았다. **사용자가 이 작업 중 엔진을 Unity로 확정하고 지금은 시스템 기획만 요청했다.** 따라서 Unity/C#을 목표로 책임과 인터페이스를 설계하며 게임 코드는 구현하지 않는다. Unity 버전·패키지·실행 환경은 설치 확인 또는 확정하지 않았다. 인접한 다른 프로젝트를 이 프로젝트의 기술 선택으로 간주하지 않는다.

## 상태와 완료의 뜻

원본 콘텐츠의 제안은 이 설계의 요구 기준으로 채택했다. 새 실행 규칙은 권장 설계이며 사용자 확정 사실과 구분한다. 문서 및 데이터 계약·예제 검증은 이번 작업의 완료 범위다. 첫 게임 구현 이정표는 **NPC와 이벤트 JSON을 추가하면 지정 장소로 이동하고 대화하며 결과가 저장되는 실행 예제**다. 그 인수 기준은 구현 계획에 있으며 아직 게임에서 달성한 결과가 아니다.

원본 파일은 수정하지 않았다. 확장 시에는 시스템 계약·스키마·예제·검증을 함께 갱신하고, 콘텐츠마다 전용 실행 코드를 복사하지 않는다.
