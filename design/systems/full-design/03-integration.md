# 연결 사례와 인수 시나리오

모든 사례는 구현할 동작의 명세다. 아래 순서와 기대 결과는 Unity 실행 로그가 아니다. 숫자는 원본 목표 또는 명시된 제안 프로파일이다.

## 수업 → 마법 응용 → 공동 프로젝트 → 관계

부유 기초(class.levitate_basic)를 완료하면 learnedSpellIds에 spell.levitate를 기록한다. 기숙사 배치 context.levitate_furniture, 무대 소품 context.levitate_stage, 탐험 무게추 context.levitate_weight는 서로 다른 고정 context 정의다. 세 번째 성공 반응 후 응용 선택이 열리며 같은 물체를 100번 옮겨도 증가하지 않는다. 무대 프로젝트 P08은 관련 수업 또는 사건 E 발견으로 열리므로 수업을 생략해도 대여 도구로 시작할 수 있다.

프로젝트의 실험 → 준비 → 설치를 수행하면 projection.p08과 참여 NPC의 activityKey를 같은 커밋에 기록한다. 미라의 첫 공동 활동 유형이면 친밀도 +8 제안값을 한 번 적용하고 다음 초대를 평가한다. 관계 R07은 인사와 공동활동1개, R08은 R07 완료+다른 공동활동2유형, R09는 R08 완료+장면 안 후속준비다. 물품 선물·기다린 날짜는 필수가 아니다. 프로젝트와 관계 장면의 목표를 겹쳐 제작시간을 이중 계산하지 않는다.

## 전투 / 장치 → 같은 A3 완료

공통 입구에서 안전 거점과 방 체크포인트를 만든다. node.a2 완료 → node.a3의 두 경로를 선택한다. 전투는 과열 인형의 예고·냉각·정지, 장치는 밸브2개·공급차단으로 outcome.a_stopped에 합류한다. 물결이 없으면 item.loan_a의 물통·펌프·공구를 무료로 쓴다. 마지막 공구 수리와 중앙 명령 evidence.a3는 공통이다.

데이터에서는 두 경로가 각각 한 Row다. event.a3_combat의 script는 `perform encounter encounter.a3`, event.a3_device는 `perform puzzle room.case_a3:device`이고 둘 다 방 활동(room-activity)이며 effects는 `complete outcome.a_stopped` 하나, completionKey는 outcome.a_stopped로 같다. 이어서 event.a3_aftermath가 `perform puzzle room.case_a3:repair` 뒤 effects `evidence.add evidence.a3 / complete node.a3 / case.reward case.a`를 한 번 커밋한다(completionKey=node.a3). 보상150크라운(원본120–180 범위의 제안, 사건 정의의 rewardCrowns)과 evidence.a3, case.a 해결 파생상태, projection.a가 이 커밋에 함께 들어간다. 나중에 다른 경로를 연습해도 node.a3 원장이 있으므로 재지급하지 않는다. A3의 해결 부분 목표6–8분과 전체 노드 평균25분은 다른 범위다. 두 경로 보상은 동일하고 재미·길이는 실제 사용자 검증 대상이다.

## 재료 → 제작 → 설치 → 월드 변화

개인 화분은 현재 wateredDay를 기록한다. 다음 일경계에 이전날 물이 있었다면 growthTicks+1, 없으면 그대로다. 성장이2–4에 도달하면 수확 가능하다. harvestPart는 잎/꽃/씨앗 중 하나만 골라 확정한다. 수확과 물품지급·빈화분 전이는 한 번의 트랜잭션이다.

자동 급수기 recipe.tool_1의 대체 재료까지 포함해 비용견적을 만든다. 커밋 직전에 재료 revision·대여 scope·가방공간을 재검사한다. 중단은 소비0, 실패실험은 정해진 범용재료로 반환, loan 혼합이면 결과 전체가 같은 scope의 loan이다. P01 설치 완료는 개인6칸 자동급수 기능을 영구 활성화한다. 도구 회수·가구 재배치가 설치 완료 플래그를 취소하지 않는다. 학교 공간도 저장된 projection으로 재구성한다.

## 시간표 → 예약 → 일정 복귀

서린은 평상 일정에 따라 실제 이동한다. 관계 초대를 수락하면 Accepted 예약이 남는다. 같은 NPC에 주요 사건 해결과 관계 장면이 동시에 Ready라면 해결400이 먼저 임대를 받는다. 관계 초대는 사라지지 않는다. 현재 실행 중인 장면에는 다른 장면이 끼어들지 않는다.

예약은 전체자원 확보 → 숨김 합류 → 장면 안 이동/대화 → 비용가산·결과확정 → 임대해제 순서다. 끝났을 때 18:00이면 18:00의 목적지를 다시 조회하고 그곳으로 걸어간다. 지나간 12:00 일정 장소까지 돌아가는 일이 없다. 일반 이동 실패를 순간이동으로 덮지 않는다.

## 저장 중 종료 → 안전 복원

서린 초대 수락 직후 scene-entry 저장 A가 만들어진다. move/대사/선택 중 저장하면 A를 기록하며 UI는 장면 처음부터라고 안내한다. 종료 후 A를 읽으면 완료·재료소비·보상은 미적용이고 예약은 Accepted, 토큰은0이다. 다시 시작해 성공하면 scene-complete 저장 B에 완료·원장·시각을 함께 기록한다. B로 다시 읽을 때 보상0추가·시간0추가다.

임시파일 쓰기·교체 사이에 종료하면 이전 정상본 또는 검증된 새세대만 로드한다. 두 세대의 지갑과 완료집합을 섞지 않는다. 방 활동은 현재 방 체크포인트로 돌아가되 확정 증거·이전 방·설치가 유지된다.
