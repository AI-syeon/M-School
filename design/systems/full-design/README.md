# 매직캠퍼스 전체 시스템 기획

2026-11-01 · Unity 구현을 위한 설계 제안 0.2 · 게임 코드 미구현

진입 문서: `design/마법학교_전체시스템기획서.html`. 기존 공통 기반의 구조도·단계 따라가기·맵 지도·제어권·정지·안전 저장 설명을 계승하고, 게임 도메인별 설명과 연결 모형, 개발용 명세를 추가한다.

## 이 문서가 정하는 것

제작자는 등록된 명령·조건·효과·도메인 작업을 JSON Row의 함수 호출 칸으로 조합한다. 새로운 적의 판단 원리, 새로운 마법 반응 알고리즘, 새로운 퍼즐 조작은 도메인 코드·어댑터·스키마·검증을 함께 추가해야 한다. 임의의 게임을 JSON만으로 만든다는 약속은 하지 않는다. 범용 상용 엔진·노드 편집기·모든 플랫폼 대응을 새로 만드는 범위가 아니다.

요구는 실제 원본 HTML의 규칙이다. 제안은 개발에 필요한 상태·식·기본값을 이번 문서가 선택한 것이다. 미정은 선택이 필요한 콘텐츠나 프로토타입 조정값이다. 원본의 수치 자체도 실제 게임 측정값이 아니라 최초 목표일 수 있다.

## 산출물

읽는 순서: README → 11-function-syntax.md(데이터 작성 형식) → 02 → 09·10 → 03 → 04 → 05 → 06.

- `11-function-syntax.md`, `schemas/functions.json`: 데이터 작성 형식. 한 행동은 함수 호출 한 칸, 한 이벤트는 한 Row. 함수 이름·인자·참조 종류는 함수 사전 한 곳에 둔다. 01–10과 기존 공통 기반의 작성 형식보다 우선한다.
- `01-source-trace.md`, `source/requirements.json`: HTML 17절의 본문과 표 343항목, 원문 위치와 연결.
- `02-contracts.md`: 기존 공통 기반과 전체 도메인의 실행·저장 경계, 명령·조건·효과 호출.
- `source/claude-draft-01.md`–`03.md`: Claude Code CLI의 Opus 5.5가 작성한 상세 명세. 통합본의 보정 계약이 우선한다.
- `03-integration.md`: 실제 연결 사례, 경계값·복구 사례와 인수 기준.
- `04-data-contracts.md`: 닫힌 스키마와 예제의 범위·필드·참조·단위.
- `05-implementation.md`: 의존성별 구현 계획과 객관적 완료 기준.
- `06-validation.md`, `validation`: 실제 문서·정적 데이터·호출 칸 검사와 미실행 범위. `validation/report.json`에 생성한 심볼 색인과 에셋 바인딩, `validation/row-reduction.json`에 형식 전환 전후 Row·객체 수.
- `08-field-dictionary.md`: 스키마에서 생성한 필드 사전과 함수 사전 표.
- `07-claude-record.md`: 실제 모델·전송 범위·수신·반영·미채택 기록.

## 원본 조사

58,122,942바이트 HTML을 읽되 16개의 내장 base64 이미지를 본문과 분리했다. 추출 본문 574행, 34,994자와 캡션·예상 UI를 구간별로 모두 읽었다. 주요 절은 17개다. 원본 표는 26개, 머리글 포함 243행이며 추적표에는 데이터행 217개와 본문126개를 넣었다. `source/original-body.html`에 모든 표·본문·화면 설명을 보존했다. 화면 이미지의 파일 해시16개를 HTML 내장 이미지와 실제 ID로 대조했고 모두 일치한다. 두 장의 접촉 인쇄 모음으로 16화면의 주제·조작 대상·구도를 확인했다. 원본 Markdown과 일관성 규칙·검토자료·기존 공통기반·템플릿·스키마·예제·검증 도구도 대조했다.

프로젝트와 상위 Workspace, 사용자 홈에 AGENTS.md가 발견되지 않았던 조사 이력과 이번 프로젝트 파일 조사 결과를 따른다. 이후 사용자가 직접 전달한 전역 지침에 따라 Claude 호출에는 computer-use나 화면·마우스·키보드 자동화를 사용하지 않고 CLI를 사용한다.

기존 `design/systems` 문서는 최소 기반의 이력이다. 이번 전체판의 확장 계약이 v1의 “전투·관계·생활 상세는 후속”이라는 제한을 대체한다. 원본과 기존 문서는 덮어쓰지 않는다. 이번에 실제 게임 프로젝트·C# 실행기·아트·완성 대사·Unity 테스트를 만들지는 않았다.

## 재생성과 검증

프로젝트 루트에서 `node design/systems/full-design/tools/build-all.cjs`로 전체판 데이터·스키마·원고채택본·세부대응표·검증·HTML을 재생성한다. 이 명령은 Claude에 요청을 보내지 않고 보존된 응답을 사용한다. 원본 추출물과 화면 검토 모음은 source에 보존했다. 최신 반영의 우선순위와 검토 지적은 10-review-resolution.md를 먼저 확인한다.
