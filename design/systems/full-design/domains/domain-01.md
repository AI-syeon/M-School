# 캐릭터·수업·마법·전투·탐험 상세

## 3. 캐릭터·입력

### 3.1 플레이어 [원]+[제]

**생성 항목**
- `displayName`: 1–10자 **[제]**
- `appearancePreset`
- `honorific`: 호칭

**상태 필드**

| 필드 | 기본값 |
|---|---|
| `hp` | 100 |
| `focus` | 100 **[원]** |
| `dodgeCooldown` | 1.0초 |
| `quickSlots[4]` | 시작 시 등불·부유 |
| `knownSpells` | — |
| `spellVariant[spellId]` | — |
| `situationLog[spellId]` | 집합 |
| `defeatCount[encounterId]` | — |

- HP와 집중력은 교전 종료 시 전부 회복합니다. 집중력은 **[원]**, HP는 **[제]**입니다.
- 비교전 상태에서 HP는 항상 최대입니다.

### 3.2 입력 행동 (논리 액션)

| 행동 | 키보드·마우스 [제] | 패드 [제] |
|---|---|---|
| Move | WASD (8방향) | 왼쪽 스틱 (8방향으로 양자화) |
| Interact | E | A |
| BasicBolt | 마우스 좌클릭 | X |
| Cast (현재 슬롯) | 마우스 우클릭 | Y |
| Slot1–4 | 1–4 | 십자키 |
| Dodge | Space | B |
| SpellRing | Q 홀드 | LB 홀드 |
| Notebook | Tab | View |
| Cancel/Pause | Esc | Menu |
| AimMode | 마우스 방향 자동 | 오른쪽 스틱 |

**조준 [원]+[제]**
- **비교전:** 사거리 3타일 안의 상호작용 가능 대상 중 점수가 가장 높은 대상을 선택합니다.
  - 점수 = 정면각 가중 0.6 + 거리 가중 0.4
  - 외곽선과 행동명을 표시합니다. 시전하면 대상형으로 판정합니다.
- **교전:** 마우스 방향 또는 오른쪽 스틱 방향을 씁니다. 보조 조준은 기본 15°(설정 0–30°) 원뿔 안에서 가장 가까운 적으로 보정합니다.
- **불가 대상:** 사람과 사유물은 대상 후보에서 제외합니다. 커서를 올리면 "할 수 없는 일" 이유를 표시합니다.

**슬롯 정책 [원]**
- 정답 주문을 장착하지 않았다고 귀환을 강요하지 않습니다. 고리에서 습득한 모든 주문을 즉시 교체할 수 있습니다.

## 4. 수업

### 4.1 정의 [원 구조]+[제 필드]

**LessonDef**
- `id`: 예 `class.water_basic`
- `source`
- `spellId`
- `kind`: basic | applied
- `tier`: intro | beginner | intermediate | advanced
- `timeCostRegular = 120`, `timeCostReview = 150`
- `supportGrant`: 재료 묶음 ID. 판매가 0 **[원]**
- `characterSceneId`
- `solutionMethods[]`: 응용은 2개 이상 **[원]**

### 4.2 해금 판정 (순수 함수, 완료 기록만 사용) [원]

| 대상 | 해금 조건 |
|---|---|
| intro basic 2개 (등불, 부유) | 도입 중 완료. 도입 시간 예산으로 산정 |
| beginner basic M03–M06 | `intro.completed` |
| intermediate basic M07–M10 | 완료한 beginner basic 서로 다른 2개 이상 |
| advanced basic M11–M12 | 완료한 intermediate basic 2개 이상 |
| applied (주문 X) | X의 basic 완료. 그 외 조건 없음 |

**원칙**
- 날짜 조건은 없습니다.
- 정규 수업과 복습은 같은 `completedLessons` 집합에 기록합니다.
- **주문 습득 = basic 완료**입니다.
- **응용 해금(주문 응용)과 응용 실습(applied 수업)은 별개입니다.** applied 수업은 응용 해금을 요구하지 않고, 응용 해금도 applied 수업을 요구하지 않습니다.

### 4.3 회차 [제]

**정규 수업**
- 수업일 09:00에 개설 2과목, 공동 실습일 14:00에 applied 1과목을 엽니다.
- 학기 시작 시 선택한 관심 과목을 개설 순위에 반영합니다.
- 해금되지 않은 과목은 개설하지 않습니다.
- 08:50에 알림을 보냅니다. 09:15까지 교실 앞에서 참여할 수 있으며, 이후에는 "다음 회차 / 실습실 복습"을 안내합니다.

**복습**
- 실습실 개방 시간 내내, 해금된 모든 과목을 할 수 있습니다.
- 교재와 대여 도구를 씁니다. 인물 장면은 '복습 모임'으로 다시 볼 수 있습니다.

**원장 키**
- 지원 재료: `class.<id>.support`. 첫 정규 출석 시 1회만 지급합니다. 복습만 한 경우 과제용 대여 재료를 쓰며, 결과물은 판매·반출할 수 없습니다.
- 완료한 수업을 다시 하면 연습 모드입니다. 보상과 상황 기록은 없습니다.

**상태 전이**
- Locked → Available → InProgress → Completed
- 중단 시 Available로 돌아가고 시간비용은 없습니다.

**실습 기록**
- `methodsUsed[]`, `bestScore`(선택 목표)를 남깁니다.
- 오답이면 피드백 후 재시도합니다. 실패 횟수는 기록만 하고 페널티는 없습니다.

## 5. 마법

### 5.1 시전 처리 순서 [원 원리]+[제 순서]

1. **선택:** 슬롯 주문과 템플릿을 결정합니다. 비교전은 대상형, 교전은 주문 정의의 전투 템플릿을 씁니다.
2. **비용:** 비교전은 0입니다 **[원]**. 교전은 `focus >= cost`를 검사하고, 부족하면 시전 불가 표시와 함께 기초 마력탄을 제안합니다.
3. **대상 허용:** 사람·사유물·`noMagic` 태그는 중단합니다. 비용을 차감하지 않습니다.
4. **조합 판정:** 대상의 현재 상태 + 이번 주문이 등록 조합(5.3)에 해당하는지 고정 순서로 첫 일치를 찾습니다.
5. **단일 반응:** 대상 태그 × 주문 반응표를 적용합니다.
6. **무반응:** 관찰 정보를 수첩에 기록합니다(예: "열에는 반응하지 않는다"). 재료는 손실되지 않습니다 **[원]**.
7. **상태 부여·지속시간 시작**, 그다음 상황 기록(5.4)을 남깁니다.

**대상 태그 [원 7종 + 제 확장]**
- 원문: wet, flammable, plant, broken, resonant, dark, mechanical
- 확장: overheated, frozen, liftable, floating, seed_dry, sound_source, shadow, illusion_screen, record

### 5.2 주문별 3템플릿·비용·효과

**템플릿 정의**
- **발사형:** 사거리 8타일, 투사체 속도 12타일/초 **[제]**
- **영역형:** 반경 1.5타일 또는 지정 원뿔
- **대상형:** 사거리 3타일 단일 대상

교전 비용과 수치는 모두 **[제]**입니다. 원문은 10–30 범위만 정합니다.

| 주문 | 대상형 (생활·탐험) | 발사형 / 영역형 (교전) | 비용 | 교전 효과 |
|---|---|---|---|---|
| 등불 | 밝기·색 조절, `dark` 해제, 숨은 잉크 공개 | 영역 r2 | 10 | `shadow` 적 '노출' 6초 (받는 피해 ×1.5) |
| 부유 | `liftable` 들기·배치 → `floating` | 발사 (물체 집어 투척) | 15 | 투척 피해 15, '준비 동작' 중인 적은 2초 경직 |
| 물결 | `wet` 부여, 오염 제거, 수위 ±1 | 원뿔 90°, 3타일 | 10 | `wet` 8초, `overheated` 해제 6초 |
| 불씨 | 가열, `frozen`·수지 녹이기 | 발사 | 15 | `flammable` 점화: 초당 3, 4초. `frozen` 해제 |
| 싹틔움 | 수확 부위 선택, 덩굴 다리·손잡이 | 영역 r1.5 | 20 | 소형 적 구속 2초, 대형 적 둔화 30% 3초 |
| 돌다듬기 | `broken` 돌 성형 → '성형됨' | 대상 지점 | 20 | 엄폐물 1개 (HP 40, 8초) |
| 돌풍 | 먼지 제거, 바람길 생성 | 원뿔 60°, 4타일 | 15 | 경량 투사체 반사, 경량 적 2타일 밀침 |
| 서리 | `wet` → `frozen` (조합 R1) | 발사 | 15 | 둔화 30% 4초. `wet` 대상은 R1 적용 |
| 메아리 | 소리 기록·재생 → `sound_source` | 영역 r3 | 20 | 시전·충전 방해 (예고 카운트 초기화) |
| 수선 | `broken` 복원 | 대상 | 20 | 아군 장치 복구, `mechanical` 적의 노출 부위 봉쇄 |
| 환영 | 상 투사, `illusion_screen` | 대상 지점 | 25 | 분신 5초 (적 공격 방향 유도) |
| 결계 | 안전막, 통과 허가 | 영역 (방향성 막) | 15 + 반사 | 정면 피해 무효 1.5초. 피격 직전 0.3초 안에 펼치면 투사체 반사 |

**기초 마력탄 [원]**
- 주문 12개에 포함하지 않으며 비용은 0입니다.
- 피해 10, 간격 0.4초 **[제]**

### 5.3 등록 조합 6종 [원 종류]+[제 순서·판정]

**판정 순서:** 한 시전이 여러 조합에 해당하면 아래 R1부터 순서대로 첫 일치 하나만 적용합니다. 조합이 단일 반응보다 우선합니다.

| ID | 선행 상태 → 촉발 주문 | 결과 | 역순일 때 |
|---|---|---|---|
| R1 물결+서리 | `wet` (물결) → 서리 | `frozen` 표면 20초 (보행 가능). 적: 빙결 1.5초 후 둔화 | 서리 먼저: "젖은 표면이 없다" 관찰 정보. 이후 물결은 단순 `wet` |
| R2 돌풍+메아리 | `sound_source` ↔ 바람길, **양방향 허용**, 6초 창 | 소리 방향 = 돌풍 방향. 공명 자물쇠·주의 돌리기 | 동일 결과 |
| R3 부유+결계 | `floating` → 결계 | 공중 정지 고정 20초 (교전 8초) | 결계 먼저: 부유 실패 "막이 들어 올림을 막는다" |
| R4 싹틔움+불씨 | `seed_dry` + 싹틔움 '발아 준비' → 불씨 | 껍질 개방 → 수확 가능. 살아 있는 `plant`에는 불씨가 항상 무효 (보호 규칙) | 불씨 먼저: 그을음 관찰 정보. 손실 없음 |
| R5 등불+환영 | 등불 광원 활성 + `record` → 환영 | 기록 장면 투사 (조사 단서 표시) | 환영 먼저: "빛이 부족해 흐릿하다" |
| R6 수선+돌다듬기 | '성형됨' ∧ '수선됨' 누적, **순서 무관**, 방 재설정 전까지 유지 | 구조물 복구 (영구 플래그로 승격) | 한쪽만 하면: "부품이 부족하다 / 결합이 없다" |

이 6종 외의 조합은 지원하지 않으며, 각 주문의 단일 반응만 적용합니다. **[원]**

### 5.4 주문 응용 해금 [원]

- `situationLog[spellId]`는 등록된 `situationTag`의 집합입니다. 예: `levitate.furniture`, `levitate.stage_prop`, `levitate.counterweight`, `levitate.combat_throw`
- 서로 다른 태그가 3개 이상이면 해당 주문의 응용 선택지가 열립니다.
- 같은 태그를 반복해도 진행 점수가 오르지 않습니다.
- 전투 태그도 인정하지만 필수는 아닙니다. 복습실 과제마다 고유 태그를 부여해 부족분을 보충할 수 있습니다.
- 응용 변경은 기숙사에서 무료입니다.

## 6. 전투

### 6.1 자원·회피·피해 [원 기준]+[제 값]

**집중력**
- 최대 100입니다.
- 피해를 받지 않고 2초가 지나면 초당 5씩 회복합니다.
- 환경 목표를 해결하면 +10입니다.
- 교전이 끝나면 전부 회복합니다. **[원]**

**회피**
- 거리 2.5타일, 무적 0.25초, 재사용 1.0초 **[제]**

**피해 등급 [제]**

| 등급 | 피해 | 기본 예고 |
|---|---|---|
| 경 | 10 | 0.8초 |
| 중 | 15–20 | 1.0–1.2초 |
| 강 | 30 | 1.4초 |

**난이도 배율**
- 편안함: 적 피해 ×0.5, 예고 ×1.5 **[원]**
- 도전: 피해 ×1.25, 예고 ×0.85 **[제]**
- 예고 시간 하한은 0.5초입니다.
- 피해량·조준 보조·예고 길이는 개별 슬라이더로 조절하며, 언제든 변경할 수 있습니다. **[원]**

**HP 회복**
- 교전 중에는 요리 소모품만 씁니다. 회복 20, 교전당 3회입니다. **[제]**

### 6.2 공격 토큰과 AI 상태

**토큰 디렉터 (교전 단위)**
- `maxTelegraphing` = 3 **[원 "기본 3체 이하"]**, 편안함은 2 **[제]**
- 적은 예고를 시작하기 전에 토큰을 요청합니다. 공격과 회복이 끝나면 토큰을 반환합니다.
- 배분 순서: 대기 시간이 가장 긴 적 → 플레이어와 가장 가까운 적
- 분열체는 부모 토큰 풀을 공유합니다.

**AI 상태**
- Idle → Notice → Position → RequestToken → Telegraph → Attack → Recover → Position
- 경직, 노출, 진정 진행 중에 맞으면 Telegraph를 즉시 취소하고 토큰을 반환합니다.

**종료 상태**
- Defeated, Pacified(진정·유도), Disabled(장치 정지)
- 셋 모두 교전 해결로 인정하며, 같은 완료 플래그로 합류합니다. **[원]**

### 6.5 패배·방 복구 [원]+[제]

**방 상태 필드**
- `RoomState{entrySnapshot, tempLoot[], confirmedFlags, encounterState}`
- 방 진입 시 `entrySnapshot`을 기록합니다.
- 방을 클리어하면 `tempLoot`를 확정 인벤토리로 이동하고 `confirmedFlags`를 저장합니다.

**패배 처리 (HP 0)**
1. 페이드 후 마지막 안전 거점으로 이동합니다.
2. 현재 방만 `entrySnapshot`으로 복원합니다. 적과 퍼즐이 다시 배치됩니다.
3. 현재 방의 `tempLoot`를 폐기합니다.
4. 이전 방 완료, 확정 단서, 열린 문, 돈, 가구는 유지합니다.

**반복 패배 지원**
- `defeatCount[encounterId]`가 3이 되면 지원 부적과 장치 해결 힌트를 제안합니다.
- 사용해도 보상·관계·엔딩 등급을 감점하지 않습니다.
- 재도전 시 설명과 컷신을 건너뛸 수 있습니다.

## 7. 탐험

### 7.1 데이터 [원 구조]+[제 필드]

**권역** `RegionDef{id, safePoints[], mainRoute[], optionalRooms[3]}`
- 4권역: `region.whisper_forest`, `region.waterway`, `region.observatory`, `region.underground_archive`

**방** `RoomDef{id, principleTag, rentalStationId, exits[], hintChain[3], staffHelpSteps[], estimatedMinutes}`

**규칙**
- 입구에 `estimatedMinutes`와 다음 안전 거점을 표시합니다. **[원]**
- 안전 거점에 처음 진입하면 귀환문을 등록합니다. 귀환문은 발견한 거점끼리만 연결합니다.
- 선택 조사실 X01–X12는 메인 필수 방과 `roomId`를 공유하지 않습니다. 로드 시 검사합니다.

### 7.2 방 진행 흐름

1. 입장하면 `entrySnapshot`을 기록하고, 필요 주문이 없을 때 대여대 위치를 즉시 안내합니다. **[원]**
2. 작은 문제로 원리를 익히고, 변형 문제로 적용합니다. **[원]**
3. 퍼즐 조작 화면에서는 calendar를 정지합니다.
4. 체류 180초가 지나면 힌트 1단계를 제안합니다. 3단계는 관찰 대상 → 성질 → 구체 행동입니다. 즉시 열람할 수 있으며 감점은 없습니다.
5. 마지막 단계 이후에는 "교직원 도움"으로 현재 방을 단계별로 동행 해결합니다. 사건을 자동 완료하지 않습니다.
6. "현재 방 초기화"는 단서를 유지한 채 퍼즐만 복원합니다.

**힌트 공유**
- 힌트 진행 상태 `hintIndex[roomId]`는 수첩과 NPC 질문이 공유합니다.

### 7.3 인수 예

1. 물결 미습득 상태로 A3에 진입하면, 입구 안내에 수동 펌프 대여대가 표시된다. 펌프로 수위를 맞추면 물결 사용 시와 같은 `waterLevel` 상태에 도달한다.
2. 23:59 교전 중에 자정이 되면 선택지가 뜬다. 교전 완료를 고른 뒤 쓰러지면 방이 복원되고 기숙사 07:00이 된다. 이때 앞 방의 확정 단서는 유지되고 이번 방 전리품은 없다.
3. 보상 커밋 직후 강제 종료하고 다시 로드하면 commit 스냅샷에서 재개하며 보상은 1회만 지급된다. 커밋 전에 종료하면 진입부터 재시작한다.
