# 예상 게임화면 시안

2026-11-01 · HTML 기획안 화면 포함판

16개 주요 콘텐츠 유형에 대응하는 AI 생성 픽셀 스타일 화면이다. 실제 구현 화면이나 확정 아트 규격이 아니다. 같은 은색 머리·보라 망토의 학생, 따뜻한 석조·목재 학교, 탑다운 시점을 공통으로 사용했다.

생성 경로는 기본 내장 image_gen 도구다. `manifest.json`에 공통 스타일 프롬프트와 각 화면의 장면 프롬프트, 캡션, 예상 UI 내용을 기록했다. 01 화면의 최초 요청은 같은 공통 스타일 아래 중앙 분수·왼쪽 교실·오른쪽 온실·게시판 앞 플레이어·등교하는 학생을 지정했고, 나머지는 manifest의 scene을 그대로 붙여 생성했다.

이미지 속 글자 대신 HTML에서 읽기 쉬운 시간·목표·주문·대화 UI를 겹쳐 표시한다. 기획안 HTML에는 PNG를 내장하므로 HTML 파일만 옮겨도 이미지가 표시된다. 이 폴더의 PNG는 원본을 따로 사용하거나 화면을 다시 편집할 때를 위해 보관한다.

이 화면들은 각 주요 콘텐츠 유형의 대표 장면이다. 모든 관계 사건 36개, 부탁 24개, 주문 12개 각각에 별도의 화면을 만든 것은 아니다.
