# Task 6–9: 게임 시스템 구현

2026-11-06 현 Core 기반 개정. 아래 작업은 미착수 계획이다. [현재 구조](구현구조.md)와 [확장 계약](../systems/full-design/02-contracts.md)을 따른다. 경로는 Assets/MagicCampus 기준이며 새 규칙은 Core, 입력/표시는 Game에 둔다. 전경은 EventRun 최대1, 상태는 GameState, 저장은 수면/02시 EndDay다. 공통 Content.cs/GameState.cs/Game.cs/Event.cs/GameRoot.cs 편집은 같은 단계에서도 순차 진행한다. 별도 규칙/시험 파일만 독립 수행할 수 있다.

새 명령/DTO/영속 필드는 해당 Task가 구현·기본값·로드 정규화·사전 검사·현재 저장 호환까지 함께 추가한다. perform/완료키/loan/방 상태 등은 현재 미구현 확장이며 기존 v2 스키마에 있다는 이유로 지원된 것으로 보지 않는다.
