# Task 1–5: 현재 기반과 첫 연결

2026-11-06 개정. 아래 16개 Task ID는 추적을 위해 유지한다. 현재 코드의 책임 단위로 재정의했으며, 모두 새로 만들어야 하는 작업이 아니다. 구현 존재와 인수 통과는 구분한다. 현 Core 검사는 [검증 결과](../systems/07-validation-results.md), 실행 구조는 [구현구조](구현구조.md), 회귀 기준은 [인수기준](인수기준.md)을 따른다.

기존 서비스 그래프·포트·전체 v2 저장을 다시 구현하지 않는다. 같은 단계의 공통 파일은 순차 수정한다. 4-2는 4-1 연결 확인 뒤 수행하며, 번호를 동시 작업 허가로 쓰지 않는다.
