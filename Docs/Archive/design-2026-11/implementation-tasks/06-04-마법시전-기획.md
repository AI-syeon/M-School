# Task 6-4 기획 카드 · 콤보 영창과 빠른 시전

**목표** · 플레이어가 배운 주문을 여러 키의 순차 입력으로 시전하고, 사용할 수 없는 이유를 주문 수첩과 화면 안내에서 확인한다. 빠른 시전 기능을 해금한 뒤에는 자주 쓰는 주문을 슬롯에 배치해 키 한 번으로 시전한다.

## 1. 콤보 영창

- 자유 조작 중 `Q`로 영창을 연다. `1`–`4`를 차례로 눌러 룬 2–5개를 입력하고 `Enter`로 확정한다. 같은 룬을 연속으로 입력할 수 있다.
- 첫 실습에서는 어두운 안내판을 바라보고 `Q → 1 → 2 → Enter`로 등불을 켠다. 주문 수첩에서 배운 주문의 룬 순서를 다시 볼 수 있다.
- 짧은 주문과 긴 주문이 같은 룬으로 시작할 수 있다. 예를 들어 `1 → 2`를 입력한 뒤 확정하면 짧은 주문을 시도하고, `3`을 더 입력하면 긴 주문을 선택할 수 있다. 완전히 같은 배열은 주문 하나에만 배정한다.
- 입력한 룬과 확정 가능 여부를 화면에 표시한다. 틀린 순서는 입력 줄을 비워 다시 시작하게 하고, 아직 완성되지 않은 입력은 룬을 더 입력하라고 안내한다. 룬 키 여러 개나 룬과 확정 키를 동시에 누르면 차례로 눌러 달라고 표시한다. 미습득 주문의 이름은 숨긴다.
- 초기안은 입력 시간 제한 없이 이동과 세계 시간이 흐르는 방식이다. `Q`, `Esc`, `X`, `Backspace`로 영창을 취소할 수 있다. 메뉴·일지·대화·이벤트를 열거나, 포털을 통과하거나, 게임 창에서 벗어나면 진행 중인 영창을 비운다. 방 재시도, 하루 종료, 불러오기에도 같은 규칙을 적용한다.

영창은 주문 하나를 선택하는 조작이다. 물결로 젖은 대상을 서리로 얼리는 기존 마법 조합은 각 주문이 발동한 뒤 대상에 나타나는 반응으로 적용한다.

## 2. 주문별 사용 조건

- 주문을 배운 상태에서 해당 주문의 사용 조건을 모두 충족해야 한다. 주문별로 특정 스탯 이상, 학과·실습 숙련 등의 레벨 이상, 특정 아이템의 가방 소지 수량을 지정할 수 있다.
- 시전할 때 현재 상태를 확인한다. 예를 들어 렌즈가 필요한 주문의 영창 도중 렌즈를 잃으면, 입력을 끝내더라도 “실습용 렌즈 1개 필요 · 가방 0개”라고 표시한다.
- 소지 조건은 가방에 있는 물품을 확인하며 사용 시 물품을 소모하지 않는다. 우편, 보관함, 과제용 임시 대여품은 초기 소지 조건에서 제외한다.
- 조건 미달, 대상 없음, 보호 대상 등의 이유를 화면에 표시한다. 이 경우 주문 효과와 비용은 발생하지 않는다. 같은 주문의 사용 조건·대상·비용은 영창과 빠른 시전에 공통으로 적용한다.

## 3. 빠른 시전 해금과 편집

- 전용 해금 주문을 자기 자신에게 처음 성공시키면 빠른 슬롯 4개를 연다. 다시 성공해도 슬롯에 넣어 둔 주문은 유지된다.
- 교전과 이벤트 밖에서 주문 수첩을 열어 슬롯별로 빠른 시전이 허용된 주문을 배치·교체·해제한다. 조건을 일시적으로 충족하지 못해도 배치는 유지된다.
- 자유 조작 중 `1`–`4`를 눌러 해당 슬롯을 즉시 시전한다. 영창 중에는 같은 키를 룬 입력으로 쓰고, 대화 중에는 기존 선택지 입력에 쓴다.
- 해금과 배치는 하루를 마칠 때 저장한다. 슬롯에 배치하지 않은 주문도 영창으로 사용할 수 있다.

## 작업 순서와 완료 기준

| 순서 | 기획 범위 | 플레이 확인 |
|---|---|---|
| 1 | 콤보 영창과 등불 실습 | 안내판을 정확한 순서로 한 번 밝힐 수 있다. 잘못된 순서, 누르고 있기, 동시 입력은 오발동을 일으키지 않는다. 대화·포털·하루 종료 후 이전 영창이 이어지지 않는다. |
| 2 | 주문별 조건과 화면 안내 | 필요한 스탯·레벨·소지 수량에 정확히 도달하면 사용할 수 있다. 조건이 부족하면 이유를 확인하고 아무 비용 없이 다시 준비할 수 있다. |
| 3 | 해금 주문과 빠른 슬롯 | 해금 전 숫자 키로 주문이 발동하지 않는다. 해금 후 슬롯을 편집하고 숫자 키로 시전할 수 있다. 같은 조건에서 영창과 빠른 시전의 결과가 같고, 하루 종료 뒤 불러와도 해금과 배치가 유지된다. |

첫 플레이테스트에서는 `Q`·숫자 키·`Enter` 조작과 룬 길이를 검증한다. 빠른 시전은 기능 전체를 한 번에 여는 안을 기준으로 삼는다. 물리 키 변경과 패드 배치는 후속 조작 설정에서 다룬다.
