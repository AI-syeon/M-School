01 / 현재 코드 · TASK 1–5

이동·이벤트·하루 저장이 공통 기반이다

구현 있음

이동·일정·약속

플레이어는 충돌과 통로 규칙에 따라 이동한다. NPC는 현재 시각의 일정에 따라 맵 사이를 이동한다. 가까운 NPC의 초대를 열어 수락하고, 플레이어가 시작할 때 이벤트가 열린다.

구현 있음

한 번에 이벤트 하나

이동·대사·선택을 순서대로 실행한다. 이벤트 중 자연 시간과 평상시 NPC 일정은 멈춘다. 성공하면 완료·보상·시간을 반영하고, 취소하면 시작 때의 배치를 복원하고 약속을 남긴다. 메뉴는 전체를 멈추고, 현재 일지·초대 화면을 열어도 시간은 흐른다.

구현 있음

07시 시작 · 새벽 02시 종료

평상시에 현실 1초당 게임 1분이 흐른다. 취침과 02시 기절은 같은 하루 종료 규칙을 쓴다. 다음 날 07시 상태를 저장하며, 중간에 종료하면 마지막 하루 저장에서 시작한다.

확인 범위 · 11월 6일 기록에서 기반 자동 검사 72개가 통과했다. 현재 코드 기준 Unity 재빌드와 Windows 조작 인수는 남아 있다. 타일 제작 기준은 32×32 픽셀이고, 기존 16픽셀 시제품 자산은 전환 대상이다.

02 / 후속 계획 · 행동과 판정

플레이어의 행동을 시스템이 어떻게 판정하나

Task 6-5 · 6-6

수첩·힌트·표시

플레이어 행동
오늘 일정, 인물 위치와 다음 일정, 사건 단서, 주문 응용, 학교 기록을 조회하고 목표를 최대 세 개 추적한다.
판정과 결과
현재 상태에서 가능한 행동과 도구 획득처를 표시한다. 힌트는 관찰 대상 → 대상의 성질 → 할 행동 순서로 연다. 힌트와 현장 도움은 보상을 유지한다. UI 배율·자막·효과 강도와 조준 보조를 설정할 수 있게 한다.
Task 7-5

수업·복습·습득

플레이어 행동
정규 수업에 가거나 실습실에서 복습한다. 실습이 틀리면 피드백을 받고 다시 시도한다.
판정과 결과
두 경로는 같은 완료 기록을 쓴다. 기초 실습 성공으로 해당 주문을 배우고, 같은 단계의 서로 다른 기초 과목 두 개를 완료하면 다음 단계 수업이 열린다. 각 주문의 응용 실습은 해당 기초 완료로 열린다. 정규 출석 없이도 복습으로 학습할 수 있다.
Task 6-4

마법·대상 반응·응용

플레이어 행동
주문을 골라 대상이나 공간에 시전한다. 같은 주문을 여러 상황에 활용한다.
판정과 결과
발동 조건과 명중을 검사하고, 보호 대상 여부 → 등록 조합 → 주문 하나의 반응 순서로 판정한다. 평상시 시전 비용은 0이며 교전 중에는 집중력을 쓴다. 한 주문을 등록된 서로 다른 상황 세 가지에서 쓰면 그 주문의 응용 선택이 열린다. 교실의 응용 실습과 별도 성장이다.
Task 6-1 · 7-4 · 8-3

탐험·방 목표·전투

플레이어 행동
방을 관찰해 주문·현장 도구·수동 조작을 고른다. 교전에서는 공격 예고를 읽고 회피하거나 대응한다.
판정과 결과
방 목표가 여러 해결 입력을 공통 성공으로 받는다. 집중력이 0이어도 기초 공격·회피·장치 사용은 가능하다. 동시에 공격하는 적은 교전 설정, 난이도 설정, 최대 3체 중 가장 낮은 제한을 따른다. 패배 시 현재 방의 미확정 적·퍼즐·전리품을 초기화하고 이전의 확정 진행은 유지한다.

수업·마법·전투·탐험 명세후속 시스템 작업

03 / 후속 계획 · 생활과 진행

활동 결과가 다음 선택지를 여는 방식

Task 6-3 · 7-7 · 8-4 · 8-5

공동 경험·관계·활동

플레이어 행동
NPC를 만나 함께 실습·모임·부탁 등에 참여하고, 조건을 채우면 도착한 초대를 원하는 때 시작한다.
판정과 결과
첫 관계 장면은 인사와 공동 활동 1회, 다음 장면은 첫 장면 이후 서로 다른 활동 유형 2개를 요구한다. 이전에 경험한 유형의 재참여도 이 조건에 인정한다. 친밀도 점수와 선물은 별도로 계산한다. 약속에 기한이 없고, 놓친 행사는 연습 회차로 경험할 수 있다.
Task 6-2 · 7-1 · 7-3

가방·거래·제작

플레이어 행동
물품을 얻거나 빌려서 거래·제작에 쓴다. 연금은 재료의 성질과 공정을 조합한다.
판정과 결과
일반품·지급품·대여품을 구분하고, 제작 결과에도 출처 제한을 이어받는다. 지급품의 판매가는 0이며 대여품은 해당 과제 안에서만 쓰고 종료 시 회수한다. 거래·제작은 조건 검사를 끝낸 뒤 차감과 산출을 함께 반영한다. 가방에 들어가지 않는 일반 보상은 우편으로 보낸다.
Task 7-2 · 8-1 · 8-2 · 8-6

재배·시설·하루 정산

플레이어 행동
물주기와 돌봄을 하고, 제작한 물건이나 공용 시설을 미리 본 뒤 설치한다.
판정과 결과
물주기를 놓치면 성장이 멈춘다. 설치는 충돌과 출입구·침대 접근을 검사한다. 하루 종료에서 끝난 날의 성장·돌봄 → 새날 자동 급수·재입고 → NPC 일정 배치 → 저장을 순서대로 처리한다. 날이 바뀔 때 같은 정산을 한 번만 적용한다.
Task 7-6 · 12-1

사건·해결 경로·최종 해금

플레이어 행동
사건을 원하는 순서로 골라 조사한다. 방에서 교전이나 장치 조작 같은 해결 경로를 고른다.
판정과 결과
각 사건 안의 발견 → 조사 → 해결 순서를 확인하며, 수락 전에 찾은 단서도 인정한다. 서로 다른 해결 방법이 같은 완료 상태와 보상으로 합쳐진다. 해결 2·4건마다 중간 정리, 6건이면 최종 실습이 열린다. 플레이어가 시작 시점을 고르고 엔딩 뒤에도 진행을 이어간다.

04 / 시스템 연결 규칙

막힘을 풀고, 완료와 저장을 구분한다

부족한 조건은 대체 경로로

수업을 놓쳤으면 복습한다. 주문이나 돈이 부족하면 무료 도구와 수동 조작을 쓴다. 전투가 어려우면 지원이나 장치 경로를 이용한다. 필수 정보와 협조는 친밀도에 관계없이 받을 수 있다.

성공은 한 번만 반영

수업·활동의 시간과 보상은 성공 시 한 번 확정한다. 교전과 장치 조작처럼 방법이 달라도 같은 목표의 완료 기록을 공유한다. 관계·시설·환경 변화도 그 완료 결과를 바탕으로 반영한다.

세 가지 복구 경계

이벤트 취소는 장면 배치와 약속을 복원한다. 방 재시도는 현 방의 미확정 진행만 초기화한다. 게임 재시작은 마지막 하루 저장을 불러온다. 최종 실습 직전 별도 보관 저장은 후속 계획의 예외다.

구현 구조 · Core가 행동의 조건·시간·보상을 판정하고, Unity가 입력과 표시를 맡는다. 새 시스템마다 규칙, 정의 데이터, 기존 저장의 기본값·호환 처리, UI와 사전 검사를 함께 추가한다.

05 / 11월 6일 개정 계획

다음 구현은 Task 5 재인수 후 Task 6이다

  1. Task 5 · 재인수

    현재 빌드에서 공통 기반 확인

    이동·초대·이벤트 선택·취소·시간 정지·취침·02시 종료·저장 복구를 현 Windows 빌드에서 확인한다.

  2. Task 6 · 기반 확장

    여러 시스템이 공유할 규칙 추가

    방 상태와 목표 실행, 가방·출처·대여, 공동 경험 기록, 주문 시전·반응, 수첩·힌트, 표시·접근성 설정을 만든다.

  3. Task 7–8 · 연결

    플레이 활동과 하루 정산 구현

    거래·재배·제작, 전투·수업·사건·관계를 공통 기반 위에 올린다. 배치·프로젝트·탐험·활동·대사와 하루 종료를 연결한다.

  4. Task 9–11 · 검증

    한 빌드에서 시스템 간 진행 확인

    수업에서 배운 주문을 다른 활동에 적용하고, 무료 대체 경로로도 같은 목표를 완료하며, 저장 후 결과가 복원되는지 확인한다. 60~90분 사용자 테스트에서는 스스로 다음 행동을 찾는지와 필수 반복 비중을 측정한다.

  5. Task 12–18 · 확장

    자유 순서와 장기 진행 검증

    독립 사건의 순서, 최종 해금과 엔딩 후 진행, 이전 저장 호환, 접근성을 확인한다. 시스템을 전체 분량에 적용한 뒤 전 구간에서 다시 검증한다.
