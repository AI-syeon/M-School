# 게임화 작업 진행 기록

## 사용자 요청 (2026-11-11 원문)

> 지금까지 작성된 기획서 무시하고 지금 현재 있는 기능들 정리 좀 해줘. 너무 보기 어렵고, 게임보다는 기능 뭉치같다. 이걸 좀 더 게임스럽게 바꿔보자고 우리. 시스템과 컨텐츠는 잘 분리하되, 게임을 좀 더 게임스럽게 바꿀 필요가 있다. 스스로 더 게임 같게 만들어줘. 아트 리소스도 제대로 만들고, UI도 더 UI/UX 고려해서 만들어줘... UI 너무 가독성이 힘들어 지금... 진짜 UI 많이 다듬어야 할 것 같아. 맵도 제대로 만들고... 만든 시스템도 다듬고 컨텐츠도 살짝만 얹어줘 컨텐츠는 내가 나중에 마이크로매니징할거야. (아트는 Codex 아트 리소스 생성 세션 참고하고 이거 끝나면 결과물 받아서 해줘.)

결정으로 다룰 것:
- 기존 기획서(`design/systems/`, `design/implementation-tasks/`)는 이번 작업의 기준이 아니다.
- 시스템(코드)과 콘텐츠(JSON)를 분리한다. 콘텐츠는 맛보기만 넣는다. 세부 콘텐츠는 사용자가 나중에 직접 정한다.
- 아트는 Codex 아트 세션이 만들고, 끝나면 그 결과를 받아 게임에 넣는다.

## 시작 시점 진단 (2026-11-11, 직접 확인)

- 게임 화면은 8×6칸 임시 타일 안뜰과 6×5칸 휴게실이다. 화면 위 1/3을 디버그용 글자, 버튼, 단축키 설명 한 줄이 덮고 나머지는 검은 배경이다. (`Tests/Results/verify/starter-1/success-notes/invite.png`)
- 시스템은 시계·하루 끝(취침/기절)·저장, NPC 일정, 약속 이벤트와 선택지, 룬 영창 마법과 태그 반응, 가방·우편함, 지도 화면이 있다. 서로 이어지는 목표가 없어서 기능 묶음처럼 보인다.
- Codex가 만든 20×14칸 안뜰 장면(`Assets/MagicCampus/CampusGrid/Generated/CampusCourtyard.unity`)은 완성도가 높지만 게임에는 들어가 있지 않다.

## 방향 (AI 제안, 사용자 확인 전)

하루 한 판 루프를 중심에 둔다.

1. 기숙사 방에서 07:00에 일어난다.
2. 안뜰 게시판에서 오늘의 의뢰(2~3개)를 본다.
3. 룬 마법으로 안뜰의 대상(안내판, 화분, 석판 등)을 바꿔 의뢰를 푼다. 친구와 약속 이벤트를 진행한다.
4. 의뢰를 끝내면 크라운과 아이템을 받는다. 화면에 토스트와 효과로 바로 보여 준다.
5. 방으로 돌아와 잔다. 하루 결과를 정리해 보여 주고 저장한다.

맵은 기숙사 방, 안뜰(Codex 장면), 휴게실을 잇는다. UI는 화면을 덮는 글자를 걷어 내고 시계·소지금 카드, 오늘의 할 일 추적, 빠른 슬롯 바, 상호작용 말풍선, 토스트로 바꾼다. 조작법은 메뉴 안으로 옮긴다.

## 최종 상태 (2026-11-11)

- 아트 6묶음(UI 키트, 아이템 아이콘, 마법 대상, 기숙사 방, 휴게실, 캐릭터) 모두 게임에 들어갔다. Codex 사용량 합계 429,065토큰.
- 사람이 직접 해 봐야 아는 것: 마우스 조작(탭 클릭, hover), 글자·빛·효과의 느낌, 하루 루프가 재미있는지.

- AI가 정한 콘텐츠 해석(사용자가 바꿀 수 있음, `world/world.json`): 이끼는 물결(젖음)로 꽃이 핌, 룬석은 메아리 효과 6초 동안만 켜짐. 기본 시작 주문은 등불·싹틔움·불씨.
- 커밋하지 않았다. 작업 폴더에는 다른 세션(지도·인벤토리, Codex 아트)의 커밋 안 된 변경도 섞여 있다.

## 도착한 아트 (2026-11-11, 메인이 미리보기 확인)

- UI 키트: `Assets/MagicCampus/Art/UI/` + manifest(9-slice). 선택 상태가 약해서 코드로 강조를 더한다. UI 작업자(D)에게 넘김.
- 아이템 아이콘 9종: `Assets/MagicCampus/Art/Items/`. id는 `item.rune_chalk` → `item-rune-chalk`. D에게 넘김. 꿀빵의 꿀, 서리박하의 서리 표현이 약하다(나중에 보완 가능).
- 마법 대상 기물 6종×2상태: `Art/CampusGrid/targets.json`, `CampusGrid/layout.json` props에 12개 id. 아직 게임에 연결 안 함. 남은 일: 대상 id+태그 → 그림 id 표를 콘텐츠에 두고 그리기, 대상 칸을 충돌로 막기, 반응 효과(빛·입자)로 약한 상태 차이 보완.
