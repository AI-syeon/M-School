# 현 기반 채택과 폐기한 전제

2026-11-06. 현재 C# 구현 사실 → 현재 실행/데이터 계약 → Task별 후속 확장 → 원본 게임 요구 순으로 기술 결정을 읽는다. 원본 콘텐츠 수량·무료경로·선택 의도는 유지한다. 이전 스키마나 도메인 초안이 현 코드에 없는 기능을 구현된 것으로 만들지 않는다.

| 항목 | 현재 채택 |
|---|---|
| 계층 | Core + Game + Game.Editor |
| 상태 | 가변 GameState와 구체 규칙 메서드 |
| 전경 | EventRun 최대1, 동기 순차 실행 |
| 콘텐츠 | Content DTO, 단순 문자열 호출, 개발 시 사전 검사 |
| 이동 | 축별 플레이어 이동, BFS NPC/이벤트 경로, 셀 진입 포털 |
| 시간 | Day/Minute, 07시 기상, 02시 기절 |
| 저장 | EndDay의 tmp/bak JSON, NPC는 일정 재배치 |
| 후속 | Core의 작은 규칙 클래스·명시적 DTO/메서드 추가 |
| 그래픽 | 32×32 타일, 기존 16px 자산은 후속 정합 대상 |

Contracts/StateStore/Handle/자원 임대/등록형 함수 전체/원본 save v2 보존/장면 진입 자동 저장/24시 귀환 전제는 폐기한다. 과거 검토 기록은 [이전 판](../../archive/2026-11-02/systems/full-design/09-adoption.md)에 보존한다.
