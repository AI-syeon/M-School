# 현재 기반 위의 연결 시나리오

2026-11-06. 첫 약속은 현재 구현이며 아래 도메인 연결은 후속 구현 계획이다. [확장 계약](02-contracts.md)을 따른다.

## 첫 약속 → 하루 저장 (현재)

NPC 범위에서 E → Offered 수락 → StartEvent → 숨김 recipe 배치 → NPC 이동 → 대사 → 두 선택 중 하나 → 해당 fork → set/currency.add → Completed(eventId) → 비용 → 약속 제거 → NPC 현시각 복귀. 이때 파일은 쓰지 않는다. 침대에서 잠자거나 02시가 되면 다음날 07시 상태를 저장한다. 로드는 그 상태를 읽고 NPC를 일정에 배치한다.

## 수업 → 응용 → 프로젝트 → 관계 (후속 6–8)

Classes가 실습 성공을 확인한 뒤 학습·고유 context·비용을 Game에서 한 번 적용한다. context는 서로 다른 정의만 센다. P08 설치는 Projects의 검증 후 설치와 참여 기록을 함께 쓴다. Experience는 평생 첫 유형 +8과 R1 이후 참여2유형을 구분하고 Relationships가 기한 없는 초대를 Appointments에 넣는다. 저장은 EndDay다.

## 전투 / 장치 → 같은 A3 (후속 6-1/7-4/7-6/8-3)

RoomRun에서 인형 전투 또는 무료 펌프·밸브 조작을 수행한다. 양 경로의 성공은 outcome.a_stopped에 합류한다. 공통 수리 후 Story의 구체 메서드가 node.a3/증거/해결/공유 보상키를 함께 기록한다. 다른 경로를 다시 실행해도 보상0이다. reset은 현 방 미확정 상태만 버린다.

## 재배 → 제작 → 설치 (후속 7-2/7-3/8-2)

끝난 날의 물준 기록으로 성장 → 다음날 초기화/자동 급수. 수확은 출처를 보존한다. Crafting은 재료·scope·공간을 먼저 검증하고 한 요청에서 소비/산출을 반영한다. Projects는 무료 대여 실험과 영구 설치 납품을 구분한다. loan 산출은 과제 밖에 반출·저장하지 않는다.

## 일정과 약속

평상 이동은 Schedule/World를 쓴다. 현재 한 전경만 시작하고 다른 약속은 남긴다. 종료 뒤 현재 Minute 목적지로 걷는다. 자동 Ready/400·300 우선순위 스케줄러는 필요하지 않다. 로드/기상은 즉시 일정 배치한다.

## 종료와 복구

그날 수락·보상 뒤 저장 전에 종료하면 마지막 하루 저장으로 돌아간다. 수면 저장 뒤 로드하면 완료/보상/약속이 같은 GameState로 복원된다. 이벤트 중 취소는 세션 Actor 복사본으로 복원한다. 별도 장면 진입 파일은 없다. 최종 실습 별도 보관 저장은 12-1의 명시적 예외다.

실제 인수 조작과 결과는 [A01–A10/T01–T22](../../implementation-tasks/인수기준.md)에 기록한다. 정적 순열 검사·Core 시험·Unity 플레이·사용자 측정은 서로 대체하지 않는다.
