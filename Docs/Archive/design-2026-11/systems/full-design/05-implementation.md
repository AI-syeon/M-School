2026-11-06. Task 번호는 단계 번호다. Task5까지의 기반은 현재 Core/Game 코드로 존재하며 새로 구축할 계획으로 표시하지 않는다. 인수 상태는 [검증 결과](../07-validation-results.md)를 따른다.
