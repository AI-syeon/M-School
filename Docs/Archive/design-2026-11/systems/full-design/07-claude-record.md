# Claude 실제 사용 기록 · 이번 전체판

작업일 2026-11-01. Codex 담당 세션은 자료 조사·조율·파일작성·정적검증을 맡고 Claude Opus 5.5는 전체 요구 분석과 세 묶음의 상세 시스템 명세를 직접 작성했다. 모델을 서로 바꿔 부르지 않는다.

## 접근과 전환

초기에는 사용자가 로그인한 Claude Windows 앱에서 실제 모델 선택 메뉴의 Opus 5.5를 확인하고, 원본HTML에서 추출한 전체 본문과 공통계약을 전송했다. 일반 대화 주소는 https://claude.ai/chat/61bbca34-bd48-4af3-aecd-eabd4ed430a8 이다. 이 일반 대화의 응답은 수신 확인하지 않았고 산출물 근거로 사용하지 않았다. 사용자가 Esc로 컴퓨터 사용을 중단한 뒤, 재개와 이후 화면자동화금지 지침을 전달했다. 그 이후 Claude의 UI 자동화를 하지 않았다.

화면 없는 공식 Claude Code CLI 2.1.309를 앱 번들에서 발견했다. 로그인 확인은 loggedIn=true, authMethod=claude.ai, apiProvider=firstParty였다. 토큰/계정주소는 출력하거나 전송하지 않았다. CLI에서 일반 앱 대화ID를 resume했으나 “No conversation found”가 반환되어 같은 대화를 이어받았다고 주장하지 않는다.

원본 전체와 공통계약을 CLI에 다시 전달했다. 최초 제한된 연결은 API 재시도로 응답을 받지 못해 중단했고, 허용된 CLI 서버연결에서 새 세션을 시작했다. **실제 세션 ID: 9e8f0844-641c-46d2-9862-e679c3900193**. 이후 회차는 전부 이 세션을 resume했다. 세션의 초기화 출력과 각 assistant 메시지가 반환한 실제 모델은 **claude-opus-5-5**다. fallback 모델은 지정하지 않았다.

CLI 실행은 `-p --model claude-opus-5-5 --tools '' --safe-mode --strict-mcp-config --output-format stream-json --verbose`다. 화면·마우스·키보드 조작 없이 텍스트만 stdin으로 전달하고, Claude 쪽 도구·파일변경을 끈 상태로 요청했다. 로컬 산출물은 담당 세션이 작성했다.
