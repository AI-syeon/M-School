## 검증 구분과 사용자 장벽

Core 시험은 dotnet run --project Tests/Core/MagicCampus.Core.Tests.csproj다. Unity 빌드 진입은 MagicCampus.Game.Editor.GameBuild.Build이며 씬을 다시 생성하므로 기존 씬 수정 보존을 먼저 확인한다. 이 문서 개정에서는 씬을 재생성하지 않는다.

60–90분 6/8명 다음 행동2개·인물1명/자발적 주문 응용, 첫2시간10/12명 도입과 다음 선택, 필수 반복20% 이하, 폭넓은 체험 중앙값36–44시간은 후속 실측 목표다. 2402분 기획 합계를 실측으로 보고하지 않는다.

기록은 코드 revision, 실제 입력 콘텐츠 해시, Unity/플랫폼, 시작 fixture, Day/Minute/이벤트, 조작, 전후 GameState, 저장 파일 유무/내용, 기대/실제/미실행으로 남긴다. 없는 tick sequence/revision/Handle 로그를 요구하지 않는다. 모델 검사·Core·Windows 플레이·사용자 결과를 구분한다.
