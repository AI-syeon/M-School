# 원본 요구와 현재 기반의 대응

2026-11-06. 원본 게임 방향과 수량은 [최초 기획안](../마법학교_최초기획안.md)을 따른다. 그 문서의 옛 기술 설명은 구현 사실로 사용하지 않는다.

| 요구 | 현재 기반 | 후속 구현 |
|---|---|---|
| 오프라인 Windows, 32×32 타일 | Unity Core/Game, Windows 빌드 진입점 | 6-6/15-7의 기존 16px 아트 정합 |
| 걸어서 만나고 약속 수행 | 입력 이동, BFS, 포털, 단일 EventRun | 콘텐츠 확장과 방 활동 |
| 대화·선택·기억·보상 | move/say/choice, eq, set/currency.add, eventId 완료 | 새로운 명령은 해당 알고리즘과 사전 검사 동시 추가 |
| 일상 시간과 NPC 일정 | 07시 시작, 1초=1분, 02시 기절, 현시각 일정 | 8-6 하루 정산, Day 기반 계절/5일 패턴 |
| 저장·복구 | 수면/기절 후 저장, JSON bak | 현재 무버전 저장 호환·추가 필드 기본값 |
| 12주문·6조합·24수업 | 미구현 | 6-4/7-5/15-1 |
| 생활·경제·12프로젝트 | 미구현 | 6-2/7-1~3/8-1~2/15-3 |
| 6사건×3노드·두 해결 경로 | 미구현 | 6-1/7-4/7-6/8-3/12-1 |
| NPC12·관계36·대화432 | 최소 NPC/약속만 존재 | 6-3/7-7/8-5/15-4 |
| 행사4·모임8·부탁24·조사실12 | 미구현 | 8-4/15-5~6 |

현재는 하루 저장 정책을 채택한다. 예전의 장면 진입/완료 자동 저장·자정 자동 귀환·범용 임대 스케줄러는 요구에서 제거한다. 무료 경로·기한 없는 초대·선물 없는 관계·엔딩 후 생활은 후속 플레이 규칙으로 유지한다. 저장 이전 하루를 잃을 수 있음을 HUD/수면 안내와 검증에 반영한다.
